# RSS Can v0.3.12

## 中文

本次版本修复订阅生成与缓存的运行问题，升级核心依赖，并补齐四平台二进制与双架构容器的发布验证。

- 修复 CSR 缓存命中时误用 HTML 解析的问题，隔离 SSR、CSR 和混合模式缓存。
- JS 规则执行受到超时限制；浏览器任务增加并发上限、全程超时和资源清理。
- 修复 Redis 初始化早于运行参数生效、规则目录处理、并发热刷新和列表更新问题。
- 正确返回上游抓取失败、响应截断和空响应错误，修复自动编码检测吞掉正文的问题。
- 管理入口默认仅允许本机访问；远程访问需要 `RSS_ADMIN_TOKEN` 和 Bearer 认证。
- 页面检查工具限制公网 HTTP(S) 目标，校验重定向和子资源，隔离显示抓取的页面。
- 迁移到上游 Go 模块，移除旧源码副本及嵌套依赖清单，保留第三方许可证。
- 升级 Redis v9.23.0、HTML-to-Markdown v2.5.2、goquery v1.13.0、cascadia v1.3.5、Sonic v1.15.5、jQuery 4.0.0 和 Moment 2.31.0。
- JSON Feed 输出升级为 1.1；浏览器规则保留私有 `$`、`jQuery` 别名，避免覆盖目标网页的同名变量。
- Release 归档包含规则、文档、许可证和 SHA-256 校验文件；Linux ARM64 与其他平台统一使用 `rssc` 文件名。

### 升级须知

管理接口 `/config/*`、`/inspector*` 的远程或反向代理访问现在需要配置 token；配置后本机请求也需要认证。缓存连接配置变更需要重启进程。页面检查工具不再访问内网目标，也不转发用户 Cookie 或使用代理。普通订阅抓取仍可使用规则中的相关配置。

Docker Hub 提供 `linux/amd64`、`linux/arm64` 镜像，使用固定版本标签升级：

```sh
docker pull soulteary/rss-can:v0.3.12
docker run --rm -p 8080:8080 -e RSS_REDIS=false soulteary/rss-can:v0.3.12
```

镜像内已包含示例规则。自定义规则可挂载到 `/rules`；需要 Redis 时，设置 `RSS_SERVER` 并启用 `RSS_REDIS`。

## English

This release fixes feed/cache runtime errors, updates core dependencies, and verifies binary archives and multi-platform container images before publishing the release.

- Fix CSR cache decoding, isolate parser caches, and enforce rule/browser timeouts with resource cleanup.
- Apply Redis configuration before client initialization; fix custom rule paths, concurrent reloads and live rule lists.
- Propagate upstream failures and truncated responses; preserve response bytes during charset detection.
- Restrict management routes to direct local clients by default. Remote/reverse-proxied access requires `RSS_ADMIN_TOKEN` and Bearer authentication; configured tokens are required locally too.
- Limit the inspector to public HTTP(S) destinations and isolate fetched markup.
- Replace historical local Go copies with upstream modules and retain their license notices.
- Upgrade Redis, Markdown conversion, DOM selectors and embedded jQuery/Moment. JSON Feed now uses version 1.1.
- Ship `rssc`, example rules, documentation, licenses and SHA-256 checksums for Linux/macOS on AMD64/ARM64.
- Publish `v0.3.12` and `latest` multi-platform images to Docker Hub, with embedded version/commit metadata and OCI labels.

Cache connection changes require a restart. Use the fixed version tag for repeatable deployments. See the README and `DEPENDENCIES.md` for configuration and retained compatibility pins.
