# RSS Can v0.5.1

Release date: 2026-11-13

## 中文

v0.5.1 是维护版本：使用 Go 1.27.4 构建，并更新依赖。功能、配置变量、归档布局和
数据格式与 v0.5.0 相同；运行时仍为 Deno 2.9.8。

### 变更

- **Go 1.27.4**：`go.mod`、Docker 构建镜像和 CodeQL 工作流统一要求 Go 1.27.4。该版本
  包含 cgo、go 命令、编译器、链接器和 `net/http` 的安全修复（GO-2026-6859）。
- **Kit 依赖**：cache-kit/v2 更新到 v2.1.2，redis-kit 更新到 v1.8.2。
- **浏览器依赖**：chromedp 更新到 v0.23.0，cdproto 更新到 v0.159.2，供浏览器（CSR）
  规则使用。
- **文档**：中英文 README 新增整体架构图，图源位于 `docs/images/`；发布归档不包含该
  图片目录，请在仓库页面查看。同时更新 Go 质量报告。

### 升级

从 v0.5.0 升级无需迁移配置或数据：按常规备份后，替换完整归档或镜像标签并重启。
回退时恢复原 v0.5.0 归档或镜像及相同配置。从 v0.4.0 或更早版本升级时，仍须先阅读
[v0.5.0 升级步骤](https://github.com/soulteary/rss-can/blob/v0.5.1/docs/upgrading.md#upgrade-v050)。

## English

v0.5.1 is a maintenance release built with Go 1.27.4 and updated dependencies.
Features, configuration variables, the archive layout and data formats are the
same as v0.5.0. Deno remains pinned at 2.9.8.

### Changes

- **Go 1.27.4:** `go.mod`, the Docker builder image and the CodeQL workflow
  require Go 1.27.4. It contains security fixes to cgo, the go command, the
  compiler, the linker and `net/http` (GO-2026-6859).
- **Kit dependencies:** cache-kit/v2 v2.1.2 and redis-kit v1.8.2.
- **Browser dependencies:** chromedp v0.23.0 and cdproto v0.159.2, used by
  browser (CSR) rules.
- **Documentation:** both READMEs gain an architecture diagram, with its source
  under `docs/images/`. Release archives do not include that image directory;
  view the diagram in the repository. Go quality reports were regenerated.

### Upgrading

No configuration or data migration is required from v0.5.0. Back up as usual,
replace the complete archive or the image tag, and restart. To roll back,
restore the exact v0.5.0 archive or image with the same settings. When upgrading
from v0.4.0 or earlier, read the
[v0.5.0 upgrade steps](https://github.com/soulteary/rss-can/blob/v0.5.1/docs/upgrading.md#upgrade-v050) first.

## Distribution

Linux/macOS AMD64 and ARM64 archives include `rssc`, executable Deno 2.9.8,
rules and license notices. Extract the complete archive and verify its SHA-256
file. Linux archives require glibc; use the Debian container on musl/Alpine.
The Docker release tag is `soulteary/rss-can:v0.5.1` for Linux AMD64/ARM64.

```sh
docker pull soulteary/rss-can:v0.5.1
docker run --rm --user 65532:65532 -p 127.0.0.1:8080:8080 \
  -e RSS_REDIS=false -v "$(pwd)/rules:/rules:ro" soulteary/rss-can:v0.5.1
```

This starts standalone mode. Follow the [Stargate deployment guide](https://github.com/soulteary/rss-can/blob/v0.5.1/example/4.with-stargate/README.md)
for team access and the [secure deployment guide](https://github.com/soulteary/rss-can/blob/v0.5.1/docs/secure-deployment.md) for
resource limits, read-only filesystems and private service networks.
